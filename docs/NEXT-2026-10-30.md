## 1. 第一件事：编译（09:00，30 min，阻断一切）

```bash
cd ~/rak && . ./env/activate.sh          # 或 .\env\activate.ps1
python3 scripts/build_workspace.py --profile jetson
```

判据：**零警告、零失败**，且最后自动跑完 `check_workspace --installed --profile jetson`。

失败处置（按报错类型分，不要一上来就改代码）：

| 报错 | 最可能原因 | 处置 |
|---|---|---|
| `rclcpp_lifecycle not found` | CMake 没找到包 | 确认 `package.xml` 的 `<depend>rclcpp_lifecycle</depend>` 与 `find_package` 都在；Jetson 上 `/opt/ros/jazzy` 一定有 |
| `CallbackReturn` 未声明 | 漏了 `using CallbackReturn = ...` | 对照 `src/rak_pointcloud/src/gpu_pointcloud_node.cpp` 的写法 |
| `LifecyclePublisher` 类型不匹配 | `create_publisher` 没换成 `create_lifecycle_publisher` | 三个驱动都已换；漏的会在这里报 |
| `ament_python_install_package` 未定义 | 缺 `find_package(ament_cmake_python REQUIRED)` | 已在 `rak_orchestration/CMakeLists.txt` 里；若仍报，检查 `package.xml` 的 `buildtool_depend` |
| `stereo_node` 重复 main | `rclcpp_components_register_nodes` 与自建 main 冲突 | 必须是 `register_nodes`（复数，只注册插件），不是 `register_node`（会生成 main） |

**过不了就停在这里**，不要带着编译错误往下走——后面每一步都建立在"能构建"上。

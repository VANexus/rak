# 底盘轮速控制升级设计 —— 自适应 PID / LQR / MPC 的取舍与路径

- **日期**: 2026-10-30 · **状态**: 提案（待 F11/F1 前置项闭合后实施）
- **关联**: `firmware-capability-spec.md` §7（抗打滑）· ADR-0007（ros2_control）·
  `CAN-BRINGUP-2026-10-30.md` §6（首日运动实测：四轮散布 0.5%、cpr≈61600、稳态误差 -7.8%）

## 0. 前置（不做完不许调参）

1. **F11**：速度反馈 ×100.2 修复（或 Jetson 契约改 1e-4 并标注）——反馈不可信，辨识就是垃圾进垃圾出；
2. **F1**：电池电压上报（负载变化对精度的影�要做模型就得起伏有数）；
3. 几何/轮径进 URDF（mecanum 正解的前提）。

## 1. 现状与目标

现状：MCU 25 kHz PI(+D，R46 角加速度域) 四轮闭环；台架实测 1 rad/s 稳态误差 -7.8%
（斜坡终点残留，疑似积分作用偏弱/摩擦前馈缺失）、四轮散布 0.5%。
目标：**稳态误差 ≤2%、四轮散布 ≤1%、阶跃超调 ≤5%、抗打滑（§7）**。

## 2. 方案分级（推荐自上而下执行，每步可独立验收）

| 级 | 方法 | 落点 | 为什么 |
| --- | --- | --- | --- |
| C1 | **摩擦前馈 + PI 重整定** | MCU（增益表） | 收益最大风险最小。-7.8% 稳态误差更像"积分太弱+静摩擦"，先补前馈（静摩擦 ~75% 占空比起步，待复测）再谈先进控制 |
| C2 | **系统辨识** | Jetson 离线（CSV 管道已就绪） | 多速率阶跃/斜坡 → 每轮一阶模型 (K, τ, L)。没有模型，LQR/MPC 全是摆设 |
| C3 | **增益调度（"自适应"的正确形态）** | MCU 查表 | 按速度分 3 段（低速/中速/高速）各一组增益，在线只做查表+插值。**不做在线自适应**：25 kHz 上在线变增益既危险又无必要 |
| C4 | **LQR** | Jetson 离线解 Riccati → 增益进 MCU 表 | 对一阶/二阶模型，LQR 输出就是"有最优性解释的 Kp/Ki"，落点仍是查表——它替代的是拍脑袋，不是替代 PI |
| C5 | **MPC** | **Jetson 层（Nav2 控制器）**，轮级明确否决 | F407 在 25 kHz 上跑不动 MPC；轨迹级 MPC 用 Nav2 现成的 MPPI/RPP（成熟轮子，ADR-0007 生态内），轮级 MPC 收益为零 |

## 3. 抗打滑与控制的接口

打滑残差（§7.2）进入控制的方式是**前馈修正 + 限幅**，不是改闭环增益：
打滑期间摩擦模型失效 → 前馈冻结为最后有效值，`/cmd_vel` 限幅 ×0.5（L3），
恢复后按斜坡回正常。闭环增益不动。

## 4. 验收（每级独立）

- C1: 稳态误差 -7.8% → **≤2%**（同台架工况）；
- C2: 模型对保持窗预测误差 ≤5%；
- C3/C4: 三段速度（0.3/1.0/2.0 rad/s）阶跃：超调 ≤5%、调节时间 ≤0.5 s、四轮散布 ≤1%；
- C5: Nav2 跟踪精度由 nav2 自己的验收管，不与轮级混测。

## 5. 明确否决

- **在线自适应 PID**（MIT 规则/神经网络整定）：25 kHz 安全攸关注入在线变参数，
  失稳模式不可枚举；收益（模型时不变，唯一时变是电池电压与摩擦）配不上风险；
- **轮级 MPC**：算力与收益双否；轨迹级用 Nav2 MPPI 现成件；
- **跳过 C1/C2 直接上 LQR/MPC**：没有可信反馈（F11）与模型（C2）的先进控制 = 自欺。

## 6. 低速测速质量（2026-10-30 台架现象的根因与修法，最高优先级）

**现象**：单轮 1.0 rad/s（≈9 counts/ms）平滑同步；编队里慢轮 0.196 rad/s（≈1.9 counts/ms）
卡顿咔咔。同一套固件——差别是**测速分辨率占比**：1 count/读数在 9 counts/ms 时占 11%，
在 1.9 counts/ms 时占 52%，控制环反馈台阶化 + 静摩擦 → stick-slip 极限环
（实测 82% 样本平坦 + 台阶跳变，CAN-BRINGUP §8）。

**修法（R76 固件，按收益排序）**：
1. **低速 1/T 混合测速**：counts/ms 低于阈值（建议 8）时切测周期法——25 kHz ISR 里
   持续读编码器计数，边沿间用 DWT 计时，分辨率从"1 count"变成"40 µs"，
   0.2 rad/s 下从 52% 误差降到 <0.1%；高速继续 M-method（1/T 高速会溢出/噪声大）；
2. **积分亚 LSB 化**：控制环积分器用 Q8 累加（遥测 R39 已这么做，环内还没），
   消除"积分整步进 → 占空比脉动"；
3. **静摩擦前馈**：起动/低速段按符号补固定占空比偏置（~75% 静摩擦占空比，待复测），
   stick-slip 的"堵"相位直接被前馈跨过；
4. **F12 丢拍计数器**（同批）。

**Jetson 侧配合**：Nav2 `vx_min`/最低轮速钳位（避免长期爬行指令）；
`rak_metrics` 的 fb 台阶统计（平坦样本占比）作为低速质量指标长期跟踪。
